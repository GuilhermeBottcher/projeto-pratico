# \## Versionamento Semântico (SemVer)

# 

# O Versionamento Semântico é um padrão de numeração de versões no formato

# `MAJOR.MINOR.PATCH` (ex: 1.0.0), usado para comunicar de forma clara o

# tipo de mudança feita em cada nova versão de um software.

# 

# \- \*\*MAJOR\*\*: incrementado quando são feitas alterações incompatíveis com

# &#x20; versões anteriores (breaking changes).

# \- \*\*MINOR\*\*: incrementado quando são adicionadas novas funcionalidades

# &#x20; mantendo compatibilidade com versões anteriores.

# \- \*\*PATCH\*\*: incrementado quando são feitas correções de bugs que mantêm

# &#x20; compatibilidade com versões anteriores.
